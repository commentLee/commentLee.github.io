# commentLee.github.io

GitHub Pages용 정적 포트폴리오 페이지입니다.

## 배포 주소

https://commentLee.github.io

## 파일 구성

- `index.html`: 포트폴리오 메인 페이지
- `style.css`: 스타일시트
- `assets/portfolio_lee_juseok.pdf`: 웹용 PDF 포트폴리오
- `.nojekyll`: GitHub Pages 정적 파일 처리 설정

## 참고

현재 PDF는 웹 게시용으로 재구성한 경량 버전입니다. 원본 이미지형 PDF를 그대로 공개하려면 `assets/portfolio_lee_juseok.pdf` 파일을 GitHub 웹 UI에서 교체하면 됩니다.
